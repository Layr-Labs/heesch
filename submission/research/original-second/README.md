# Optimal fractional score with Kaplan’s promoted second-ring patch fixed

**Claim.** Hold fixed the central tile and the first two complete rings from promoted submission `908a0696-f1fb-48e5-9bd9-5a301e65620a` for Kaplan’s 15-cell polyhex. Over all legal extensions of this patch, the maximum Hc-track score is **4 + 251/254 = 4.988188976377953…**. An extension attaining the bound is included as `tie.heesch`. The proof concerns the 285 occupied cells through ring two of this particular hexagonal shape. It also applies to any valid decomposition of the same fixed occupied region through ring two, since subsequent complete rings and their contact boundaries are determined by that occupied region. Changing the second-ring footprint or the generating tile lies outside the claim.

The new part is closure of the three previously unresolved third-ring footprints, designated 001, 002 and 005. The material in this directory concerns the 15-cell hexagonal comparator. The result derives no score or claim for the separately submitted 20-cell shape.

## Exhaustive search over third-ring occupied sets

The fixed 285-cell patch has 129 required neighbors. A legal third-ring tile must contain some required cell. The enumeration aligned every cell of each allowed orientation with every required cell, discarded overlap with the fixed patch, and deduplicated occupied sets. This gives 1,367 initial placements. The model iteratively discards a placement when choosing it would leave some required cell without any compatible disjoint placement. That criterion is necessary for a complete ring and leaves 243 choices. The set of fourth-ring placements is generated by the same containment argument on the union of possible third-ring boundaries. A candidate is required to actually touch the chosen third ring. Every completed ring must cover the preceding patch’s full boundary, using disjoint tiles.

After each CP-SAT solution, the benchmark’s flood fill checked both complete rings. For an enclosed component, keeping all its currently occupied boundary cells and leaving a cell of the component empty would preserve a hole. A cut therefore requires removal of at least one movable tile from that wall or coverage of the pocket cell. For each independently verified complete fourth ring, the search excluded the third ring’s entire occupied-cell vector. The original promoted third-ring occupied set was excluded before starting. After nine distinct replacements, the remaining model was infeasible. Hole-free fourth rings require one of those nine replacement footprints or the promoted footprint. Later search depends only on a third-ring occupied set, so keeping one representative decomposition per set covers every subsequent geometry. The nine representatives and the terminal infeasibility result are in `inner-patches/` and `enumeration.log`.

## Objective and boundary-size argument

For a complete four-ring patch write `B` for the size of its required fifth boundary, and `d` for the number of missed required cells plus extra enclosed cells. Its score is `5 − d/B`. A strict improvement over `4 + 251/254` requires the integer inequality `3B − 254d ≥ 1`.

The original joint solve made the fourth and partial fifth rings variable. It excluded strict gain on the promoted footprint and six alternatives, 003, 004, 006, 007, 008 and 009. The relaxed CP model returned `INFEASIBLE` directly. A timeout on footprints 001, 002 and 005 had left the fixed-P2 bound open.

For each remaining footprint, `boundary_bound.py` constructs an independent fourth-ring exact-cover model and maximizes the upper envelope of its possible fifth-boundary size. An exposed-cell variable can equal one only when at least one fourth-ring neighbor is selected and the cell itself is unoccupied. At a maximum all such cells can be counted independently. Fourth-ring holes are permitted in this model, increasing its domain. The resulting maxima are therefore upper bounds on the boundary of any admissible hole-free fourth ring.

| 001 | 291 | 372 | `d ≤ 4` | `INFEASIBLE`, 2.76 s | `INFEASIBLE`, 3.61 s |

In each case the damage limit is `floor((3Bmax − 1)/254)`. The three original joint models, with all fifth-tile domains retained, prove strict gain infeasible when given these logically implied bounds. The redundant constraints make the propagation much faster. Each model preserves feasible geometric packings because required-neighbor and occupancy indicators are exact, while the modeled damage starts as a lower bound on actual flood-fill damage. Infeasibility of this relaxation also excludes an improvement satisfying the full pocket check.

The extra-cut reruns discard a fifth tile when it conflicts with every possible fourth-ring cover of a required cell, or when no disjoint contacting fourth tile exists. They also exclude jointly selected fourth/fifth tile pairs that make a required inner cell impossible to cover or force more fifth-boundary misses than the derived damage budget. These extra tests are absent from the full-domain reruns in the table. For calibration the version with these extra cuts recovered a verified 254-cell boundary with damage three and score exactly equal to the threshold.

Together, the ten strict infeasibility results rule out any score above the claimed number for four complete rings followed by a partial fifth. The certificate from the promoted shape excludes a complete fifth ring globally. Extensions with fewer than four complete rings cannot reach this fractional score under the benchmark scoring rule. The accompanying tie construction attains the upper bound.

## Replay

Run from this appendix directory in an environment with the benchmark’s `heesch_verify` package and OR-Tools 9.15.6755. The `--geometry-only` switch suppresses copying the historical proof file when writing a geometry sample. These finite conditional optimization runs do not consume a plane-nontiling certificate.

```sh
t=$(mktemp -d)
python joint.py --source source-four.heesch --complete-four --distinct-domain \
  --sample-domains 12 --workers 3 --seconds 90 --geometry-only \
  --output "$t/domains/witness.heesch"
python boundary_bound.py \
  inner-patches/witness-001.heesch inner-patches/witness-002.heesch \
  inner-patches/witness-005.heesch --seconds 30 --workers 3
for n in 001 002 005; do
  b=372
  d=4
  if [ "$n" = 005 ]; then b=320; d=3; fi
  python joint.py --source "inner-patches/witness-$n.heesch" \
    --boundary-max "$b" --damage-max "$d" --target 1 --workers 3 \
    --seconds 300 --geometry-only --output "$t/results/$n.heesch"
done
python joint.py --source source-four.heesch --boundary-max 336 --damage-max 3 \
  --conditional-support --target 0 --workers 3 --seconds 75 --geometry-only \
  --output "$t/calibration/tie.heesch"
python -m heesch_verify tie.heesch
```

Repeat the loop with `--conditional-support` to reproduce the alternative domain-filtered tests. `boundary-bounds.jsonl` records the three upper bounds and the original-footprint calibration bound of 336. `strict-replays.json` records all six new feasibility tests, including raw and filtered domain sizes. `first-nine-tests.json` contains the earlier tests for the nine replacement footprints. `promoted-negative.log` and `tie.log` give the original-footprint upper bound and equality check. These are reproducible finite CP-SAT infeasibility results. The separate DRAT certificate on the promoted shape addresses global non-tiling and performs a different mathematical check.
